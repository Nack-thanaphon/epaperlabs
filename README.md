# Papa

Standalone handwriting board. Open in the browser, write, lasso-copy a PNG, paste into ChatGPT.

```text
https://epaperlabs.vercel.app
→ write with Apple Pencil
→ lasso copy image
→ paste into the ChatGPT box
```

Install as a PWA (Home Screen app):

- **iPad/iPhone:** Safari → Share → Add to Home Screen
- **Mac:** Chrome/Edge → install icon in the address bar, or Safari → File → Add to Dock

```bash
npm test
npm run dev
npm run build
```
